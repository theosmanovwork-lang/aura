# Aura — мобильное приложение (лента коротких видео + «волны» + виртуальная валюта «аура»)

Приложение для РФ по мотивам идеи Giggles: Be Early. Решение владельца: на время разработки дизайн можно копировать с референсов (прототип, только для закрытого показа); перед публичным релизом всё заменить на своё. Что именно заменить — список в `docs/DESIGN.md`, раздел «Заменить до релиза».
Полный план и чекбоксы этапов: `docs/PLAN.md`. Юридические вопросы: `docs/LEGAL-CHECKLIST.md`.

## Стек
React Native + Expo + TypeScript, Expo Router, expo-video, react-native-svg, expo-image-picker, expo-sqlite,
Jest + React Native Testing Library, ESLint + Prettier. Приложение лежит в корне репозитория.

## Команды
- `npm install` — установка зависимостей
- `npx expo start` — запуск (QR-код для Expo Go на телефоне)
- `npm test` — тесты; `npm run lint` — линтер; `npm run typecheck` — типы
- `npm run check` — линтер + типы + тесты (запускать после каждого этапа)

## Жёсткие рамки продукта
- В v1 НЕТ реальных денег: ни ставок, ни пополнения, ни вывода, ни криптовалют. Только виртуальная валюта «аура» (раньше «искры») без денежной стоимости.
- Решение владельца: виртуальная торговля Аурой (вложить в видео и забрать) разрешена, как и комментарии, Hub, чаты, карточки. Реальные деньги, покупка Ауры за деньги, подписки за деньги, вывод остаются запрещены.
- 2026-10-23: владелец снял ограничения на формулировки: в интерфейсе можно «ставка», «пополнить», «заработать», «вывод» и т.п. как на макете. Кнопки только нарисованы; платёжного кода нет, подключение реальных денег — отдельная задача с юридической проверкой.
- Кошелёк — журнал операций (ledger), запись только добавлением; вид актива `POINTS`. Платёжный код не писать.
- Не утверждать, что что-то «точно законно»: юридические вопросы идут в `docs/LEGAL-CHECKLIST.md`.

## Соглашения по коду
- Все тексты интерфейса на русском и только из `src/i18n/ru.ts`.
- Цвета только из темы: `useColors()` и `makeStyles((colors) => ({...}))` из `src/theme`; приложение светлое или тёмное по настройке телефона, лента всегда тёмная. Шрифты Onest и Unbounded.
- Данные неизменяемые: возвращать новые объекты, не мутировать.
- Доступ к данным только через интерфейсы репозиториев (`src/data/repositories`); правила в `src/domain`, без UI.
- Файлы до 800 строк, функции до 50 строк, ранние возвраты вместо глубокой вложенности.
- Входные данные валидировать на границах; ошибки обрабатывать явно, не глотать.
- Секреты и ключи не хранить в коде; демо-видео и ресурсы только с разрешающей лицензией.
- TDD: сначала тест (RED), потом код (GREEN), потом рефакторинг; покрытие не ниже 80%.

## Процесс работы
- Один этап за раз, строго по `docs/PLAN.md`; функций вне плана не добавлять.
- После каждого этапа: `npm run check`, ревью кода, отметить чекбокс в `docs/PLAN.md`, коммит.
- Коммиты: `feat:`, `fix:`, `test:`, `docs:`, `chore:`, `refactor:`.
- Работать в ветке `claude/hopeful-euler-we8qgx`. Ничего не пушить в `main` и не создавать PR без просьбы пользователя.
- Пользователь новичок: объяснять действия простыми словами, без жаргона.
