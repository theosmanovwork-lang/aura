# aura

Приложение «Аура»: лента коротких видео, «волны» и виртуальные «искры» (без денег). Закрытый прототип.

## Посмотреть на телефоне

1. Установите на телефон **Expo Go** (App Store или Google Play).
2. На компьютере с Node.js: `npm install`, затем `npx expo start`.
3. Отсканируйте QR-код: камерой на iPhone или сканером внутри Expo Go на Android.

## Сборка Android (APK) для знакомых

Нужен бесплатный аккаунт на expo.dev. Пароли никому не передавайте, вход делаете вы сами.

1. `npm install -g eas-cli`
2. `eas login`
3. `eas build --platform android --profile preview`
4. По окончании сборки EAS даст ссылку на APK. Скачайте файл на Android и установите его (разрешите установку из неизвестных источников).

Идентификатор приложения `ru.aura.demo` временный; поменяйте его в `app.json` (`android.package`, `ios.bundleIdentifier`) до первой сборки, если нужен свой.

Для iPhone знакомых остаётся только Expo Go: платный аккаунт Apple из России недоступен.

Перед показом читайте `docs/LEGAL-CHECKLIST.md`: пока нет подтверждения 18+ и согласия на обработку данных (этап 11), приложение показывают только лично.
